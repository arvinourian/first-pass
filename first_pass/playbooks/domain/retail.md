# Retail and E-Commerce Data Context
If this dataset involves store sales, e-commerce, customers, or retail:
1. Always analyze Seasonality and time-series trends (Weekly/Monthly sales).
2. Calculate Basket Size and Customer Lifetime Value (CLV).
3. Analyze sales variations across different Store locations or departments.
4. Assess the impact of promotions, holidays, or discounts on volume.
