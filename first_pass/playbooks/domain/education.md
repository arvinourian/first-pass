# Education and Student Data Context
If this dataset involves students, colleges, test scores, or education ROI:
1. Always analyze outcomes based on demographic or socioeconomic segments if available.
2. For College data, group by institution tier/selectivity and major category.
3. Compare debt-to-earnings ratios (ROI) as a primary metric for higher education.
4. Assess temporal graduation rates and dropout risk factors.
